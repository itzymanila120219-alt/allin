ALL IN, MIDZY Memory Match

Open index.html in a modern browser or upload this entire folder to GitHub Pages.

Features:
- 20-card deck with 10 matching pairs
- Balanced Back1 and Back2 card backs
- Responsive desktop, tablet, mobile, and landscape layouts
- Opening 1.5-second deck preview on the first game
- Large one-card match spotlight with the member name
- Consecutive match streak display
- Face-up matched cards with a faint red glow
- Moves, timer, accuracy, and independent best time / fewest moves tracking
- NEW BEST finish celebration
- Default sound effects and supported-device haptics
- No external libraries or build process
